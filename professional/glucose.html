Artificial Intelligence for Glucose Level Prediction using Wearable Device Data with and without A Food Log

A multi-task machine learning study predicting personalised glucose levels from wearable physiological signals — evaluating classification, regression, and time-series forecasting models, and assessing whether including a food log improves predictive performance.

GitHub →

Background

Diabetes is a metabolic disorder caused either by cells of the pancreas that are unable to produce enough insulin (type 1 diabetes) or by insulin resistance (type 2 diabetes), both resulting in high glucose levels in the blood. As of 2022, diabetes affects 830 million people worldwide, a number that is expected to significantly increase over the next decades. For those affected by this disease, continuous glucose monitoring (CGM) systems help in measuring glucose values in real-time, allowing individuals to react appropriately through diet, medication, and lifestyle. However, CGM devices come with limitations: they are invasive, requiring a sensor to be placed under the skin, and expensive, with costs ranging from $100 to $400 per month.

Wearable devices already measure a rich set of physiological signals — electrodermal activity (EDA), skin temperature, photoplethysmography (PPG), and accelerometry — that reflect changes in the autonomic nervous system associated with glucose fluctuations. Using wearable devices that measure these physiological signals to predict glucose values non-invasively would consequently greatly improve the current situation. Additionally, even though prediabetes cases are increasing, many remain undiagnosed. Such devices could also enable continuous, non-invasive monitoring for early detection.

This project investigated three prediction tasks of increasing complexity — classification, regression, and forecasting — and additionally evaluated whether including a food log as an additional data source improves model performance.

Dataset

The dataset used was the publicly available BIG IDEAs Lab Glycaemic Variability and Wearable Device Data dataset (Physionet, v1.1.2). It contains data from 16 participants aged 36 to 65 years old, 7 males and 9 post-menopausal females, with an HbA1c value between 5.2% and 6.4%, thus in the high normal to prediabetic range. Over 8 to 10 days the participants wore both a Dexcom G6 CGM and an Empatica E4 wristband and were asked to keep a food log.

The Dexcom G6 CGM device measured interstitial glucose levels at 5-minute intervals. The Empatica E4 wristband contains four sensors measuring PPG, EDA, skin temperature and accelerometry. In addition, participants were asked to keep a food log with information on the time and duration of food intake, as well as on the nutritional value of the foods consumed.

Each glucose value was assigned one of the classes PersHigh, PersLow or PersNorm based on its deviation from the participant's own rolling 24-hour average. The PersHigh label was assigned if the glucose value was above one standard deviation from the average of the previous 24 hours; PersLow if below; and PersNorm if within.

Data Preprocessing & Feature Extraction

The preprocessing and feature extraction was done according to the methods described in Bent et al.'s framework using the wearablecompute GitHub repository. A total of 46 Empatica E4-derived features were calculated using a 5-minute rolling window without overlap. In addition, 20 features were calculated using food log data, and 3 additional features — gender, HbA1c, and time from midnight — were extracted from the demographics file.

To handle missing values, data availability was visualised for each participant across all sensor streams. Any 5-minute datapoint was discarded if at least one of the wearable features had a value of zero, indicating the feature could not be computed from the available sensor data. The remaining datapoints were concatenated to one consecutive sequence, resulting in a labeled dataset of 26,267 datapoints.

Feature Engineering & Correlation Analysis

Feature importance was analysed for both the classification and regression tasks, using a Leave-One-Group-Out (LOGO) cross-validation strategy to ensure data from each participant was used as a test set once. For the classification task a Random Forest (100 trees) and an XGBoost Classifier were compared; for the regression task a Random Forest Regressor and an XGBoost Regressor were compared.

Feature correlation analysis was subsequently performed using the Spearman correlation coefficient with a threshold of 0.8. Between two highly correlated features, the one with the lower feature importance was dropped. This was performed four times — separately for Random Forest and XGBoost, and for classification and regression — resulting in feature sets of 27–32 non-correlated features. Food log-derived features were always retained, as they could be dropped subsequently if not needed.

Three Prediction Tasks

01
Classification — Personalised Glycaemic Category Each glucose reading was classified into one of three personalised classes (PersHigh, PersNorm, PersLow). Two Decision Tree pipelines were compared — a Repeated Stratified K-Fold CV with recursive feature elimination (RFE), and a 70/30 Train/Test Split — alongside a TabPFN pretrained in-context learner. Class imbalance was addressed via random downsampling, continuous-sequence removal, and SMOTE oversampling.
02
Regression — Interstitial Glucose Value Predict the current interstitial glucose concentration in mg/dL. Both a population model (LOGO CV) and a personalised model (50/50 split per participant) were trained. Within each fold, a Random Forest Regressor (50 trees) selected features with importance above 0.005, which were then used to train an XGBoost Regressor. TabPFN was also evaluated as a regression model alongside the XGBoost models.
03
Forecasting — Future Glucose Trajectory Predict future glucose values across multiple prediction horizons (6–48 timesteps, corresponding to 30 min to 4 hours). A Temporal Fusion Transformer (TFT) was trained using pytorch-forecasting, and SeqFusion — a zero-shot time-series forecasting framework that sequentially fuses diverse pretrained models — was evaluated without any task-specific training.

Feature importance analysis consistently identified EDA-related features, activity-related features, and circadian rhythm signals — particularly time from midnight — as most predictive, reflecting the strong circadian regulation of insulin sensitivity and the relationship between glucose and autonomic nervous system activity. Gender and HbA1c were also highly important, consistent with known sex differences in glucose metabolism.

For the classification task, the TabPFN Classifier achieved the highest accuracy (up to 88.2%), outperforming both Decision Tree models. Dropping food log features improved TabPFN accuracy by up to 4%. For the regression task, the personalised XGBoost model performed slightly better than the population model in terms of accuracy (up to 84.5%) while the population model achieved lower RMSE values (15.6 ± 2.67 mg/dL). The Temporal Fusion Transformer achieved 92.0% accuracy for 6-hour forecasting (RMSE 15.0 ± 2.8 mg/dL).

A key finding across all tasks: dropping food log-derived features did not significantly impact the accuracy or RMSE of the regression and forecasting models. This is practically significant — it means a fully non-invasive, food-log-free wearable system is feasible for glucose monitoring. SeqFusion's zero-shot results (97.2% accuracy at prediction horizon 6) further highlighted the potential of pretrained model transfer to digital health domains where labelled data is scarce.
